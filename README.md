## Sobre o Workshop

Este workshop tem como objetivo introduzir conceitos práticos de IA e ML por meio de atividades guiadas e desafios que estimulam o aprendizado. Todo o material necessário está disponível neste repositório.

---

## Estrutura do Repositório

- [`2025.2`](2025.2/): Pasta referente ao ano de aplicação.
  - [`Desafio_SEUNOME_2025.2.ipynb`](2025.2/Desafio_SEUNOME_2025.2.ipynb): Notebook principal do desafio.
- [`assets/`](assets/): Pasta com imagens e outros recursos utilizados no repositório.

## Como Participar

1. Faça uma cópia do notebook do desafio.
2. Renomeie o arquivo trocando `SEUNOME` pelo seu nome.
3. Desenvolva a solução seguindo as instruções do notebook.
4. Envie o notebook por e-mail conforme as instruções abaixo.
